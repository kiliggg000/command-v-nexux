# Data Dictionary — CLC2026 Synthetic Dairy Demand (HK PARKnSHOP)

This package contains **simulated** store‑level dairy demand for the Corporate Link
Challenge 2026. The source data contain **no real sales**; every `qty_*` field is
generated by `generate_datasets.py` from real *explanatory* inputs (price/promo,
weather, calendar, store location, competitor proximity).

## Three controlled variants (same grid, independent samples)

Generated on a 140 stores × 120 SKUs × 366 days grid, then rolled up to weekly.

| Variant | What it is | Role in the experiment |
|---|---|---|
| **D1** (`qty_d1`) | Pure noise: i.i.d. Negative‑Binomial at D2's realised marginal mean/variance, same 86.8% censoring. No time/store/SKU structure. | False‑positive floor / leak gate; a model's error must never fall below σ. |
| **D2** (`qty_d2`) | Realistic log‑linear demand surface from defensible relationships + overdispersion + censoring, calibrated to the USDA tonnage sanity band. | Primary evaluation; coefficient‑recovery test (known truth). |
| **D3** (`qty_d3`) | D2 surface **plus** 2–3 deliberately weak planted terms (amplified supermarket competition, promo×competition interaction) + a zero‑effect spurious covariate. | Retrieval / detection test; false‑positive control. |

Because the three are independent random samples, compare them **only on aggregated
metrics** (error distribution, recovery rate, CI coverage, false‑positive rate) — never
per‑number.

## `dairy_weekly_d1d2d3.parquet`  (PRIMARY, ~890k rows)

One row per `(store, sku, week)`. Weekly = 7‑day blocks from 2024‑01‑01 (`week_index` 0–52).

| Column | Type | Meaning |
|---|---|---|
| `store_id` | str | PARKnSHOP flagship store id |
| `store_name` | str | Store name |
| `district_zh` | str | District (18 districts) |
| `Product Code` | str | SKU id (matches `sku_master.csv`) |
| `Product Name` | str | SKU name |
| `Brand` | str | Brand |
| `type` | str | Dairy type (10 types) |
| `pack_kg` | float | Pack size in kg |
| `week_index` | int | 0–52 |
| `week_start` | str | Start date of the 7‑day block |
| `qty_d1` | int | D1 simulated weekly units |
| `qty_d2` | int | D2 simulated weekly units |
| `qty_d3` | int | D3 simulated weekly units |
| `spurious_z` | float | Zero‑true‑effect covariate (per store‑SKU, constant over time). Included so models can be tested for falsely "finding" it. |

## `dairy_weekly_demo.csv` / `.parquet`  (~127k rows)

Subset: 40 SKUs × 60 stores × week. Columns: `store_id, Product Code, type, pack_kg,
week_index, week_start, qty_d1, qty_d2, qty_d3, spurious_z`. For quick EDA.

## `dairy_daily_recovery.csv` / `.parquet`  (~439k rows)

Subset: 30 stores × 40 SKUs × 366 days. Columns: `store_id, Product Code, type, date,
iso_weekday, is_weekend, is_general_holiday, rainfall_mm, promo_flag, depth_pct, qty_d1,
qty_d2, qty_d3, spurious_z`. Used for the daily coefficient‑recovery experiment.

## `sku_master.csv`  (real, 120 rows)

| Column | Meaning |
|---|---|
| `Product Code`, `Product Name`, `Brand` | SKU identity |
| `Category 2`, `Category 3` | Original category hierarchy |
| `type` | Collapsed 10‑type dairy taxonomy |
| `pack_kg` | Pack size (kg) |
| `shelf_life_days` | Product‑intrinsic shelf life (type‑derived) |
| `storage_condition` | Chilled / Ambient |
| `pack_type` | Single / Multipack / Carton |

## Real explanatory inputs (not sales)

`daily_features_2024.csv` (calendar + weather + daily promo/price summary),
`sku_daily_prices_2024.csv` (per‑SKU‑day promo flag + `depth_pct`),
`store_weights_140.csv` (district‑population store weights), `competitor_features.csv`
(500 m competitor counts), `store_weights_140.csv`. See `README.md` for the full manifest.

## Reproducibility

`generate_datasets.py` regenerates everything from the cleaned inputs using frozen seeds
and coefficients recorded in `generation_run_config.json` (β0 calibration, dispersion,
censoring rate, planted‑term sizes, achieved tonnage, zero rates, noise‑floor check).

## Licence / provenance note

All `qty_*` data are synthetic and generated by this project. **No external Kaggle / FMCG
dataset is bundled** — external sources were considered only as optional out‑of‑sample
calibration references and are excluded to keep the submission self‑contained and the
recovery experiment valid.
