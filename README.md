# 香港公开数据：中文文件名版

先打开 `先看这里_每份数据是什么及怎么用.csv`。里面按文件列出：是什么、怎么用、重点字段、连接方式和注意事项。

## 建议使用顺序

先看01价格优惠、02节假日日历、03天气、04地区人口。它们分别对应价格/促销、时间、天气、地区特征。05是补充价格快照。06至08需要进一步的门店位置或地图处理。09至10用于核对假期和数据来源。

这些都是香港解释变量，没有百佳分店真实销量。取得真实销量标签后，才可以比较各输入是否提升香港门店预测准确率。不要把价格当销量，也不要把香港天气连接到海外门店。

## 每个文件的意思

### 01_香港乳品相关商品每日价格与优惠_2024.csv

**是什么：** 2024年各连锁超市的乳品相关商品标价和优惠。每行是某次快照中的一个商品在一家连锁的价格。

**怎么用：** 观察价格、优惠变化；同商品跨连锁比价，作为竞争价格代理。

**重点字段：** archive_date：快照日期；Product Code：商品代码；Supermarket Code：连锁代码；Price：港币标价；Offers：优惠原文。

**连接方法：** 按商品代码和快照日期比较；以后需真实零售商SKU对照才能连接门店销量。

**注意：** 连锁价格，不是分店价格或销量；缺4天；包含奶饮料及人造牛油。

### 02_香港每日节假日日历_2022至2027.csv

**是什么：** 每天一行，列出星期几、周末及香港公众假期标记。

**怎么用：** 为每天增加周末、特殊节日等预测输入。

**重点字段：** date：日期；is_weekend：是否周末；is_named_holiday：是否具名假日；is_general_holiday：是否公众假期。

**连接方法：** 将销量日期与date按香港本地日期连接。

**注意：** 公众假期包含每个星期日；不代表超市关门，不等于法定雇佣假日。

### 03_香港每日天气_2020年至2026年10月25日.csv

**是什么：** 每天一行的香港天文台天气摘录，含气温、湿度、降雨等。

**怎么用：** 为历史每天增加温度、湿度、降雨等输入。

**重点字段：** date：日期；mean_temperature_c：平均气温；mean_relative_humidity_pct：平均湿度；rainfall_mm：降雨；rainfall_trace：微量雨标记。

**连接方法：** 将销量日期与date按香港本地日期连接。

**注意：** 不是逐店天气；缺2026年7月31日；微量雨数值留空，不能当零；未来预测应使用当时可得天气预报。

### 04_香港18区人口年龄收入及住户资料_2021普查.csv

**是什么：** 18区各一行，共209个字段，包含人口、年龄、收入、住户、房屋等普查特征。

**怎么用：** 描述门店所在地区的人口结构和购买力。

**重点字段：** dc：统计处区代码；dc_eng及dc_chi：区名；t_pop：总人口；age_1至age_5：年龄组人口；其他字段查字典。

**连接方法：** 先确认真实门店所属区，再以dc连接；与边界数据配合时先用第08份代码对照。

**注意：** 2021年静态资料，不是2026年人口，也不是实际顾客画像。

### 05_香港各连锁全品类价格与优惠_采集于2026年10月26日.csv

**是什么：** 采集时可下载的全品类商品价格和优惠快照，包含乳品及其他日用品。

**怎么用：** 查看商品代码、连锁覆盖及当前公开价格，或重新筛选商品类别。

**重点字段：** Category 1至3：商品分类；Product Name：商品名称；Product Code：商品代码；Supermarket Code：连锁；Price及Offers：价格及优惠。

**连接方法：** 同一快照内按Product Code跨连锁比较。

**注意：** 仅一次下载快照；来源未提供价格生效日，不能回填到2024年历史。

### 06_香港住宅楼宇组群人口及住户资料_2021普查.csv

**是什么：** 比18区更细的住宅楼宇组群统计，共3322行，包含正式组群与其他楼宇记录。

**怎么用：** 若以后取得组群边界和真实门店位置，可研究更细的周边人口特征。

**重点字段：** bg：楼宇组群代码；bg_eng及bg_chi：名称；bg_ind：B正式组群或O其他楼宇；t_pop：人口。

**连接方法：** 需要额外空间边界和门店位置，才能确定门店对应哪个组群。

**注意：** 当前包没有楼宇组群多边形；不能直接凭本表计算500米商圈人口；不是每行都为正式组群。

### 07_香港18区地图边界_原始几何.csv

**是什么：** 18区各一行，geometry_geojson字段保存该区地图多边形。

**怎么用：** 有真实门店经纬度后，判断门店属于哪个区，或绘制地区地图。

**重点字段：** had_district_code：民政署区代码；district_en及district_zh：区名；geometry_geojson：多边形。

**连接方法：** 在地图或空间分析工具中做点落在哪个多边形的判断，再用第08份对照接人口表。

**注意：** 不是门店位置表；几何坐标顺序是经度、纬度；当前边界与2021年边界可能不同。

### 08_地图地区代码与人口普查区代码对照表.csv

**是什么：** 18区的民政署字母代码与统计处数字代码对应关系。

**怎么用：** 把第07份地图边界与第04份人口资料连接起来。

**重点字段：** had_district_code：地图代码；census_dc：人口普查代码；district_zh：中文区名。

**连接方法：** 第07份had_district_code连接本表，再以census_dc连接第04份dc。

**注意：** 代码对照依据唯一中文区名；不证明不同年份边界完全一致。

### 09_香港具名公众假期清单_2022至2027.csv

**是什么：** 只列具名公众假期，不包含普通日子。

**怎么用：** 查阅官方假期名称或核对第02份每日节假日日历。

**重点字段：** date：假日日期；holiday_name_en及holiday_name_zh：名称；source_url：官方来源。

**连接方法：** 如做预测通常直接使用第02份，不要把本表未出现的普通日子误当缺失销量。

**注意：** 普通星期日没有逐一列在此表；2022至2024中文名称在选定来源中不可得，留空。

### 10_每日价格档案日期及来源索引_2024.csv

**是什么：** 2024年362次已下载价格快照的日期、行数、原ZIP和文件位置。

**怎么用：** 检查哪些日期有公开档案，追溯第01份每条价格的来源。

**重点字段：** archive_date：档案日期；archive_timestamp_hkt：香港时间戳；source_archive及source_member：原文件位置；source_url：下载链接。

**连接方法：** 以archive_timestamp_hkt对应第01份价格表。

**注意：** 这是档案目录，不是商品价格或销售观测；缺失日期不能当零销量。

## 其他文件

- `csv/`：10份中文名称的数据CSV。数据内容和原版完全相同，逐份校验过哈希。
- `数据清单_含原始来源与文件校验.csv`：覆盖日期、行数、来源链接、限制及SHA-256。已更新为本包中文文件名。
- `字段字典_按中文文件名查找.csv`：每个字段的详细解释；新增中文文件名列便于查找。

- `download_log*.json`：原始下载时间、网址和哈希。
- 人口普查原注释及知识产权公告也已保留。来源权利人包括香港特区政府、统计处、天文台、民政事务总署、1823及消委会，使用时保留来源归属。

本次只更改文件名称及使用说明，CSV内部字段保留原代码，避免与官方字段字典失配。2024价格档案缺9月23日、11月26日、12月18日和12月19日；天气源缺2026年7月31日。缺日没有填造。人口资料为2021年静态普查。代码及商品标识导入时宜按文本读取，以保留前导零。
